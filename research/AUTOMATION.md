## [실적 갱신과 자동화]

실적이 나올 때마다 출처와 기존 가정을 다시 확인할 수 있도록, 공시 확인과 계산 과정을 나눠 정리했다. 입력 자료를 검토한 뒤 계산 스크립트를 실행하면 전망과 평가표를 다시 만들 수 있다.

하이닉스 저장소에는 파일을 올리거나 변경 요청을 만들 때 템플릿을 검사하는 GitHub Actions가 있다. 이 검사는 정해둔 형식과 입력 규칙을 확인한다. 사업 전망이나 목표주가의 타당성까지 판단하는 기능은 아니다.

삼양식품과 하이닉스의 새 공시를 확인하는 별도 알림도 설정해둔 이력이 있다. 2026년 11월 2일 확인 시 두 알림은 일시정지 상태다. 알림의 역할은 새 실적과 수정할 항목을 알려주는 데까지이며, GitHub 보고서와 목표주가를 자동으로 덮어쓰도록 설정돼 있지는 않다.

현재 작업 순서는 공시 확인 → 실제치 대조 → 전망과 자본거래 검토 → 재계산 → 저장소 반영이다. 자동화 설명에서도 실행 중인 기능과 검토가 필요한 단계를 구분해두려고 한다.

자료: [하이닉스 검증 workflow](https://github.com/tobynn/sk-hynix-equity-research/blob/main/.github/workflows/validate.yml). 알림 상태는 2026.11.03 설정 확인 기준이다.
