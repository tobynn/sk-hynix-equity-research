# Valuation Framework

## 1. 역할 분담

| 방법 | 판단하는 것 | 중심 입력 | 결과 해석 |
|---|---|---|---|
| SOTP | 제품별 이익의 질과 자본수익을 구분한 사업가치 | HBM/AI DRAM, 범용 DRAM, NAND/eSSD, 기타의 정상화 이익과 사업별 배수 | 중심 가치. 부문끼리 이익·투자·순현금을 중복 계산하지 않음 |
| DCF | 이익이 CAPEX와 운전자본을 거쳐 현금으로 남는가 | 매출·마진·세율·CAPEX·재고·WACC·terminal g | SOTP의 현금전환 검증. 회계이익만으로 성장 가치를 정당화하지 않음 |
| Cycle-adjusted PER | 시장의 정상화 이익 배수와 상대적 가격 | cycle EPS와 적격 peer anchor | 정상화 가정과 시장 가격의 교차 점검 |
| RIM/PBR-ROE | 현재 장부가치 위의 초과수익이 얼마나 지속되는가 | 기초 BPS, ROE 경로, 자기자본비용, payout | 자본수익률이 정상화되는 경우의 하방·초과이익 지속기간 점검 |

모델 간 결과를 산술 평균하지 않는다. 차이가 크면 성장 지속기간, 현금전환, 자기자본비용 또는 정상화 이익 중 무엇이 다른지 설명한다.

## 2. SOTP: 하이닉스의 수익원을 분리

| 부문 | 핵심 수익 요인 | 우선 지표 | 배수 선정 원칙 |
|---|---|---|---|
| HBM 세대별 제품 | 세대·고객 인증·수율·패키징·계약 물량 | 세대별 출하/매출, ASP 방향, good-stack yield, 마진, 고객 집중 | 장기 이익 지속성이 확인된 범위만 premium. 초기 램프의 peak 마진을 영구화하지 않음 |
| AI/서버용 일반 DRAM | 고용량·고속 제품 믹스, 서버 플랫폼 채택, DDR5 전환 | 제품 믹스, ASP, bit 출하, 재고·리드타임 | HBM 배수를 전용하지 않고 서버 수요와 범용 가격 사이클을 함께 반영 |
| 클라이언트·모바일 DRAM | PC/스마트폰 출하, 콘텐츠 용량, 재고 조정 | bit demand, 고객 재고, spot/contract ASP | 완전한 메모리 사이클의 중간 이익에 맞춤 |
| NAND·eSSD/Solidigm | wafer cost, 적층 전환, 데이터센터 SSD 믹스, 가동률 | NAND ASP·원가, eSSD 비중, inventory, 감가상각 | NAND 전용 운영 자료로 산정. DRAM 배수와 혼합하지 않음 |
| 기타·조정 | 비메모리·공통비·연결조정 | 공시 부문 실적과 공통비 | 근거가 없으면 보수적으로 두고 corporate cost를 별도 차감 |

사업부 이익이 공개되지 않으면 그 값은 분석가 추정이라고 표시한다. 추정치를 공시 실적처럼 서술하지 않는다. HBM과 일반 DRAM 사이 웨이퍼·원가·공통비를 배분하는 규칙을 문서화하고, 모든 HBM DRAM 다이를 두 부문에 중복 계상하지 않는다.

## 3. 배수와 프리미엄의 근거

하이닉스의 프리미엄을 “AI 노출” 하나로 설명하지 않는다. 다음 요소가 확인될 때만 프리미엄의 방향을 인정한다.

- **이익 지속기간**: 세대별 고객 인증과 차세대 제품 이동이 연속적으로 확인되는가.
- **초과수익률**: 정상화 ROIC/ROE가 자본비용을 넘어서는 기간이 늘어나는가.
- **현금 전환**: 순이익이 CAPEX·운전자본 이후 FCF로 바뀌는가.
- **주문 가시성**: 계약·고객 다변화가 재고 사이클 노출을 실제로 낮추는가.
- **자본 부담**: 선단공정, 패키징, 신규 팹 투자로 기존 주주가 부담하는 자본이 얼마나 커지는가.

각 항목은 관측 지표·출처·발표일·증거 수준·상향/하향 조건을 기록한다. 동일 위험을 매출 성장률, 이익률, 배수 조정에서 두 번 반영하지 않는다. 배수 프리미엄을 과거 상대 multiple과 연결해 보정할 수 없다면 고정 `x` 조정치를 확정된 사실처럼 제시하지 않는다. 이때는 anchor 배수의 범위와 민감도로 결과를 보여준다. 자세한 절차는 [Peer Selection Scorecard](PEER_SELECTION_SCORECARD.md)에 있다.

## 4. DCF: 재투자와 정상화를 분리

- 매출은 제품군별 bit 성장과 ASP 변화를 구분한다. 가격 상승만으로 매출 성장을 영구화하지 않는다.
- 영업이익률은 업황 고점의 초과 마진, 중간 사이클, 하락기의 마진을 시나리오로 나눈다.
- CAPEX는 유지 투자와 성장 투자를 구분한다. 공개 자료가 없으면 추정 구분임을 표시한다.
- 운전자본에는 메모리 가격과 재고일수의 동시 변화를 반영한다. 가격 상승기에 재고자산이 늘어나는 효과를 누락하지 않는다.
- WACC는 평가일의 무위험 금리·시장 위험 프리미엄·베타·부채 비용·자본구조를 기록해 산출한다. 타깃 WACC만 제시하지 않는다.
- terminal value는 정상화 마진과 지속 가능한 재투자를 사용한다. terminal g가 장기 경제성장·산업성숙도와 맞는지 확인한다.
- WACC × terminal g 표와 CAPEX/마진 민감도 표를 함께 제시한다.

## 5. RIM: 장부가치와 초과이익 경로

`Equity Value = 시작 자기자본 + 향후 초과이익의 현재가치`를 기본으로 한다. 초과이익은 `순이익 - 자기자본비용 × 기초 장부가치`로 정의하고, payout·유상증자·자사주·배당을 장부가치 경로에 연결한다. 높은 업황 ROE를 terminal ROE에 그대로 넣지 않는다. Base·Bull·Bear별 ROE 정상화 시점과 자본비용을 분리하고, 자본비용이 장기 ROE보다 높은 구간의 초과이익은 음수로 반영한다.

## 6. 결과 충돌을 설명하는 규칙

| 관찰된 충돌 | 먼저 확인할 것 |
|---|---|
| SOTP가 DCF보다 높음 | 사업부 배수에 HBM 지속기간이 과도하게 반영됐는지, CAPEX·재고가 빠졌는지 |
| PER가 SOTP보다 낮음 | cycle EPS가 peak인지, Micron anchor 정상화가 맞는지, premium 근거가 증거와 연결되는지 |
| RIM이 현저히 낮음 | ROE 하락 경로·자본비용·초과이익 지속기간·자기자본 업데이트가 일관적인지 |
| 순현금이 커지는데 equity value가 낮음 | 주식수·환율·리스/차입금·비지배지분의 EV-to-equity bridge 확인 |
| Bull과 Base 차이가 작음 | 세대 전환 성공·수율·가격·CAPEX의 비선형 효과가 누락됐는지 |

## 7. 기준일과 분석 vintage

모든 출력은 [Valuation Vintage Policy](VALUATION_VINTAGE_POLICY.md)의 컷오프를 사용한다. 주가와 공시 실적의 시점이 다른 표를 한 결과값에 섞지 않는다. 기준일을 바꾸면 가격·환율·순현금·주식수·peer 가격·전망치 vintage를 함께 갱신한다.
