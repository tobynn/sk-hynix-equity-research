## [01. 투자 판단과 예상주가]

HBM과 서버 메모리의 이익을 평가하면서 금융상품 평가이익이 순이익을 크게 높인 효과를 분리한다. 공개된 반기 자본과 신주 발행을 반영하고, 메모리 수익성 정상화와 대규모 투자가 주당가치에 남기는 차이를 계산한다.

| 방법 | Bear | Base | Bull | 계산의 역할 |

| DCF | 776,300원 | 1,520,000원 | 2,287,700원 | 중심 시나리오: 투자 이후 영업현금흐름 |

가격 비교에는 5개 기업 모두 **2026-10-16 NAVER 일별시세 참고 종가**를 사용했다. 이 기업의 참고가는 **1,265,000원**, DCF Base와의 차이는 **20.2%**다. 배당을 제외한 연말 시나리오 가격차이며 확률적 기대수익률이 아니다. [PX01](https://api.finance.naver.com/siseJson.naver?symbol=000660&requestType=1&startTime=20261016&endTime=20261016&timeframe=day)

세 방법은 할인율·성장·분배 가정을 공유한다. PER와 RIM은 독립적인 시장 증거로 세지 않으며 평균 목표가를 만들지 않는다. 소형기업의 시장가격이 기본 사업 가치와 다르면 미확인 신규 사업의 가치나 이익 지속성에 관한 추가 가정을 확인해야 한다. 해당 가격 차이만으로 시장가격이 틀렸다고 결론 내리지 않는다.

핵심 반증은 고객 인증·수율·ASP 하락이다. 다음 실적에서는 이 조건과 현금 회수를 먼저 확인한다. 핵심 실적의 원자료는 [S01](https://dart.fss.or.kr/report/viewer.do?rcpNo=20260814003509&dcmNo=11537406&eleId=19&offset=290538&length=206708&dtd=dart4.xsd)에서 확인할 수 있다.

**[이번 점검의 판단]** 장기 초과 ROIC를 0으로 둔 DCF는 1,459,900원다. 순현금의 낮은 수익률을 분리한 RIM 민감도는 550,200원로 기존 RIM과 차이가 난다. 기존 Base의 산식과 숫자는 보존하고, 이 차이를 조건부 가치의 핵심 한계로 명시했다. 같은 이론 PER를 고정해 참고가격을 설명하려면 정상 영업이익률 40.0%가 필요하다. 이는 신규 전망이나 관측 시장 프리미엄이 아니다. 자세한 전환 가정과 기업별 수치 점검은 09·11절을 따른다.

## [03. 산업 분석과 이익이 결정되는 과정]

HBM은 메모리 다이를 적층해 가속기의 대역폭과 전력 조건에 맞춘다. 매출은 출하 stack 수와 세대별 가격으로 만들어지고 수익은 die 원가·적층 수율·패키징·테스트·초기 양산 비용을 반영해야 한다. HBM에 투입된 die를 범용 DRAM 출하량에 또 포함하면 생산능력을 중복 계산하게 된다.

HBM의 공급 가시성과 범용 메모리 가격의 순환은 기간이 다를 수 있다. 고부가 제품 비중이 높아지더라도 범용 DRAM·NAND의 증설과 재고 조정이 연결 마진에 영향을 준다. 고객의 AI 투자 예산과 실제 메모리 주문·납품·대금 회수의 시차를 확인해야 한다.

NAND는 비트 공급·공정 전환·기업용 SSD 제품 구성으로 원가와 이익을 분석한다. NAND 비교기업의 이익 배수를 DRAM에 적용하거나 HBM 배수를 소비자 NAND에 적용하지 않는다. 전방 수요를 보여주는 NVIDIA와 자체 생산설비를 부담하는 메모리 회사도 다른 비교 집단이다.

위 문단의 수요·가격·원가 연결은 공개된 사업 특성을 바탕으로 한 분석자의 해석이다. 총주소시장(TAM), 점유율, 고객별 단가가 공개되지 않은 부분에는 임의 숫자를 채우지 않았다. 산업 성장이 회사의 동일 성장률을 보장한다는 가정도 사용하지 않는다.

## [08. PER: 정상화 EPS와 배수의 계산]

첫 단계는 2027E 매출 288,002.0에 중간 사이클 영업이익률 40.0%를 적용해 정상 이익을 구하는 것이다. 보고 이익과 정상 이익은 다르다. 세금·주주 귀속·순현금 수익을 반영한 정상화 EPS는 **124,401원**이다. 반복되지 않는 평가이익과 일시적 세금 환입을 제외한다. 현금과 비영업 투자자산은 PER 결과에 별도로 더하지 않는다. 이는 DCF의 자산 가산과 계산 범위가 다르다.

둘째 단계는 5년 동안의 EPS 성장률 6.0%와 증분 ROE 20.0%를 적용한다. 성장기 배당 가능 비율은 1 - 성장률/ROE = **70.0%**다. 이후 성장률 2.5%와 성숙 ROE 13.0%를 적용하면 성숙 배당 가능 비율은 **80.8%**다. 이는 성장 투자 후 이론상 분배 가능한 이익 비중이며 회사의 실제 배당 계획과 다르다.

계산식: EPS_t = EPS_2027 × (1+성장기 성장률)^(t-1). 2026년 말 가치 = 2027~2031년 배당가능액의 현재가치 합 + [2032년 정상 EPS × 성숙 배당가능비율 / (자기자본비용-성숙 성장률)]의 현재가치. 이 값을 2027년 정상 EPS로 나누면 forward PER가 된다. 미래 기간 수와 적용 배수를 모두 공개하므로 임의 프리미엄율이 필요하지 않다.

Base 정당화 PER는 **10.18배**, 정상화 EPS는 **124,401원**, 곱한 주당가치는 **1,266,300원**다. 이 배수는 관측된 peer PER가 아니다. 성장·ROE·요구수익률 가정으로 도출한 이론 배수다. 회사별 정량 peer 자료가 확보되면 그 분포 안에서 해당 배수가 왜 다른지 대조한다.

## [09. RIM: 지배주주 자본과 잔여이익]

RIM은 주주가 이미 보유한 자본에 미래 초과이익의 현재가치를 더한다. 6월 말 지배주주 자본 262,380.6에서 H2 순이익 57,099.8를 더하고 배당 7,000.0·자사주 0.0를 빼며 신규 납입 37,109.9를 더하면 2026E 말 자본 **349,590.4**이 된다. OCI와 추가 자본거래는 0인 시나리오다.

매년 잔여이익 RI_t = 지배주주 순이익_t - 자기자본비용 × 기초 지배주주 자본_t. 기말 자본 = 기초 자본 + 순이익 - 배당. 다음 해 기초 자본은 전년 기말과 연결한다. 전체 순이익을 연결 자본총계와 섞거나 반기 실제 자본에 연간 순이익 전부를 더하지 않는다.

성숙기 ROE 13.0%와 자기자본비용 11.0%를 사용한다. 2032년 RI는 **(성숙 ROE - 자기자본비용) × 2031년 말 자본**이다. 2031년 말 자본은 이미 2032년 기초 자본이므로 여기에 성장률을 한 번 더 곱하지 않는다. 이후 RI가 장기 성장률 2.5%로 증가한다고 두어 (자기자본비용-g)로 자본화한다. Base RIM 주당가치는 **902,100원**다.

2032년 FCFF는 2031년 대비 **8.7%** 변한다. 성장률 g만큼 증가하는 경로와 다를 수 있다. 이는 투자액·마진 경로에서 성숙 ROIC 기반 재투자로 전환하기 때문이다. 장기 투자수익률과 재투자율의 관계를 먼저 확인하고 이 전환을 자연스러운 연속 성장으로 설명하지 않는다. [방법론 M02](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)

2031년 말 순현금 대용액은 자본의 **47.9%**다. 기존 RIM의 성숙 ROE 13.0%는 이 현금을 포함한 전체 자본에 적용된다. 현금이 세후 2.5%만 벌면 같은 ROE를 유지하려면 영업자산의 추가 수익이 필요하다. 다음 표는 이 부담을 분리한다.

| RIM 장기 가정 | 조건부 주당가치 | 해석 |
| --- | --- | --- |
| 전체 자본에 기존 성숙 ROE | 902,100원 | 기존 Base 입력의 결과 |
| 2032년부터 ROE = 자기자본비용 | 762,200원 | 명시기간 후 추가 초과수익 0 |
| 순현금·잔여 장부자본 수익률 분리 | 550,200원 | 현금 2.5% / 잔여 자본 13.0% |

현금 분리식: C = min(max(2031년 말 순현금,0),2031년 말 자본), NI_2032 = (B-C) × 성숙 ROE + C × 세후 현금수익률. 여기에서 도출한 전체 ROE는 **8.0%**다. 이후 자본과 각 부분이 g로 함께 증가한다고 가정해 RI를 자본화한다. 순현금은 차입금 차감 후 금액이며 B-C는 영업자본의 대용 구분이다. 관계기업·투자자산과 영업부채를 계정별 분리한 실제 영업자본이 아니므로 이 값을 새 확정 RIM으로 채택하지 않았다. 음의 terminal RI는 현금을 낮은 수익률로 계속 보유하는 조건의 비용이다. 초과현금 즉시 배당·재투자 대안은 별도 정책 경로가 필요하다. 세 RIM을 평균하지 않는다.

## [10. DCF: 매출에서 자유현금흐름까지]

FCFF = EBIT × (1-정상 세율) + 감가상각·상각 - CAPEX - 핵심 운전자본 증가. NWC는 매출채권+재고-매입채무로 정의한다. 다른 영업성 자산·부채와 선수금·성과급·세금 납부 시차는 별도 추정하지 않아 실제 현금흐름과 차이가 날 수 있다. CAPEX 전망에는 공정 유지·증설·무형 및 신규 리스 대체투자에 필요한 총투자 가정을 포함한다. 미래 신규 리스 투자 누락은 DCF를 높일 수 있어 투자 민감도에서 확인한다.

| NOPAT | 120,384.8 | 111,366.9 | 101,343.9 | 94,442.9 | 89,596.4 |
| D&A | 23,000.0 | 29,000.0 | 35,000.0 | 41,000.0 | 47,000.0 |
| CAPEX | 60,000.0 | 65,000.0 | 68,000.0 | 68,000.0 | 68,000.0 |
| NWC 증가 | 2,525.5 | 835.2 | 1,038.0 | 365.1 | 327.0 |

2026년 말부터 각 연도 말까지 1~5년의 연말 할인 방식을 쓴다. Base WACC는 10.0%다. 이는 재현 가능한 시나리오 할인율이며, 같은 날짜의 국채금리·베타·ERP를 모두 확보해 추정한 시장 CAPM 결과로 주장하지 않는다. 자기자본비용은 11.0%다. 자본구조가 거의 무차입인 소형기업은 두 값의 차이를 작게 두고, 자본집약도가 높은 반도체 회사는 높은 요구수익률 범위를 점검했다. 별도 임의 규모 프리미엄은 추가하지 않았다.

성숙기 FCFF_2032 = NOPAT_2031 × (1+g) × (1-g/ROIC). Base g는 2.5%이고 성숙 ROIC는 13.0%다. 성숙기 재투자율은 19.2%다. 마지막 해 FCF를 그대로 영구 연장해 성장투자를 누락하지 않는다. 성숙 ROIC가 WACC로 수렴할 때 성장률 상승의 가치 효과가 작아지는지도 확인한다. [M02](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)

### [참고가격 역산과 독립성 점검]

DCF·RIM·이론 PER는 할인모형이라는 공통 기반을 가진다. 특히 이론 PER는 배당가능이익의 할인값이고 RIM도 같은 clean-surplus 조건에서 DDM과 일치한다. 세 값의 근접을 세 개의 독립적인 증거로 세지 않는다. 실제 peer 가격·동일 시점 정상 EPS를 확보한 상대가치 검증은 별도 보완 항목으로 유지한다.

| DCF 가치 구성 | 원/주 |
| --- | --- |
| 2027~2031 FCFF 현재가치 | 375,800원 |
| 2032년 이후 잔존가치 현재가치 | 842,500원 |
| 연말 순현금 | 175,400원 |
| 비영업 자산 - 비지배지분 | 126,400원 |

| 단일 가정 점검 | 주당가치 | 고정한 조건 |
| --- | --- | --- |
| 2032년 ROIC = WACC | 1,459,900원 | 명시기간·g·연말 현금 고정 |
| 2027년 이후 영업마진 2.0%p 하락 | 1,447,200원 | 매출·투자·WACC·ROIC 고정; terminal 마진도 하락 |
| 2027~2031 CAPEX 20.0% 증가 | 1,452,000원 | D&A·매출·terminal ROIC 고정; 추가 수익 없음 |

기존 DCF와 ROIC=WACC DCF의 차이는 **60,200원**로 장기 초과수익 가정의 기여분이다. 고정된 terminal NOPAT에서 ROIC=WACC이면 TV=NOPAT_2032/WACC가 된다. 명시기간이나 성장 전환이 다른 별도 사업 시나리오의 값으로 사용하지 않는다. CAPEX 스트레스는 추가 투자에도 매출·잔존가치의 보상이 없는 비용 충격이다. 실제 증설 투자는 D&A·수율·출하량을 함께 재추정해야 한다.

| 참고가격을 연말 가격으로 고정한 역산 | 필요 조건 |
| --- | --- |
| 필요 2032년 FCFF(십억원) | 51,722.8 |
| 필요 2032년 영업이익률 | 24.4% |
| 이론 PER 고정 시 필요 정상화 영업이익률 | 40.0% |

역산은 2026-10-16 공급사 참고가격이 2026년 말에도 같다고 둔 조건 비교다. 관측일의 시장이 실제로 이 가정을 가격에 반영했다고 단정하지 않는다. DCF는 명시기간 FCFF·연말 현금·자산·ROIC·g·할인율을 고정하고 terminal FCFF와 마진만 푼다. 필요 FCFF = [참고가격×주식수/1,000 - 연말 순현금 - 비영업 자산 + 비지배지분 - 명시기간 FCFF PV] × (1+WACC)^5 × (WACC-g). 마진은 이를 2032년 매출×(1-세율)×(1-g/ROIC)로 나눈다. 음수나 100% 초과가 나오면 해당 고정조건에서 영업마진으로 설명하기 어렵다는 신호다. PER 역산은 이론 배수·정상 이자수익을 고정한다. 두 역산을 새 전망으로 넣지 않는다.

이론 PER 값 중 성숙기 분배가능이익의 현재가치 비중은 **71.7%**다. 현재 정상 EPS를 정확히 잡아도 성장 기간·성숙 ROE·요구수익률의 근거가 약하면 이 배수는 충분히 검증되지 않는다.

### [기업 고유 가정의 수치 점검]

가격변동 위험이 있는 단기투자자산 38,724.4와 별도 비영업 자산 92,411.3에 20.0% 가치조정을 적용하면 감소 지분가치는 26,227.1십억원, DCF는 **1,484,000원**다. 현금성 예금 전체를 위험자산으로 처리하지 않았다. 조정률은 세율이나 관측 가격 하락률이 아닌 합성 가치 민감도이며 세금을 추가로 중복 차감하지 않는다. 단기자산 손실이 발생해도 영업현금흐름·이자수익은 고정한 국소 점검이다.

ADR 조달 USD 26.5071bn의 원화 환산율이 100원 변하면 연말 현금·자본은 2,650.7십억원, DCF 주당가치는 **±3,600원** 변한다. 환율이 움직일 때 전사 해외 매출·비용도 같게 변한다고 가정하지 않은 조달액 환산만의 효과다. 실제 납입 환율·발행비·투자 집행이 확인되면 1,400원 가정을 교체한다. 조달금의 CAPEX 사용을 차감할 때에는 새 영업자산의 수익도 함께 계산해야 하므로 전액 유휴현금 보유와 투자 확대를 같은 현금에 중복 적용하지 않는다.
